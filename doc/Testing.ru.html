13. Критерии приёмки версии 1

  1. При запуске отображается дерево от корневой директории, заданной в настройках.
  2. Дерево содержит четыре колонки в порядке: Иконка, Дата, Имя, Размер; дата — в формате YYYY-MM-DD; для каталогов дата — mtime, размер — пусто.
  3. Клик по заголовку колонки циклически переключает три состояния сортировки с корректным индикатором (нет, ▲, ▼).
  4. Двойной клик по файлу открывает его во внешней программе; контекстное меню содержит «Открыть», «Открыть содержащую папку», «Копировать путь».
  5. Изменения на диске в раскрытых узлах отражаются автоматически; F5 обновляет дерево.
  6. Диалог «Справка → Настройки…» позволяет изменить корневой путь и видимость скрытых; изменения применяются и сохраняются.
  7. Пункты «Вид → Увеличить шрифт» и «Вид → Уменьшить шрифт» изменяют размер шрифта интерфейса по Ctrl + и Ctrl -; масштаб сохраняется между запусками.
  8. Пункты «Справка → Светлая тема» и «Справка → Тёмная тема» переключают тему оформления; выбранная тема сохраняется и восстанавливается при следующем запуске.
  9. В меню «Справка» порядок пунктов: «Настройки…», разделитель, «Русский», «Английский», разделитель, «Светлая тема», «Тёмная тема», разделитель, «О программе» (последним).
  10. Недоступный путь и ошибки чтения обрабатываются без аварийного завершения.
  11. Приложение запускается в CI-образе без дисплея в режиме smoke-теста (если это требование будет принято — см. раздел 14).
